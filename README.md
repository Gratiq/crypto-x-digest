# Crypto-X daily digest

Ежедневный дайджест постов из списка крипто-аккаунтов X. Обновляется ежедневно.

Постоянные ссылки на последний выпуск:
- Архив: https://github.com/Gratiq/crypto-x-digest/raw/main/latest/digest.zip
- Дайджест: https://github.com/Gratiq/crypto-x-digest/raw/main/latest/digest.md
- Все посты (JSON): https://github.com/Gratiq/crypto-x-digest/raw/main/latest/posts.json
- Посты аккаунта: https://github.com/Gratiq/crypto-x-digest/raw/main/latest/accounts/<handle>.md (или .json)
- Дата выпуска: https://github.com/Gratiq/crypto-x-digest/raw/main/latest/DATE.txt

Архив по датам: папки `YYYY-MM-DD/` с той же структурой, например https://github.com/Gratiq/crypto-x-digest/raw/main/2026-11-22/digest.zip
